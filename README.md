# CARBON

**CARBON** is a serif typeface designed by Shahabas M.

A typeface family built for modern typography and digital design.

## Font Family

| Font | Style |
|---|---|
| CARBON Regular | Regular |
| CARBON Bold | Bold |
| CARBON Italic | Italic |

## Installation

1. Open the `Fonts` directory.
2. Download your preferred `.ttf` file.
3. Install the font on your device.
